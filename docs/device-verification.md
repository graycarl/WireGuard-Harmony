# 真机验证清单（决策 0007 第二层）

> 本清单覆盖**本地单测无法验证**的平台原语与系统行为（本地单测的 `@kit` API 是空桩，
> 见 AGENTS.md「核心设计决策 3」）。每一项都是「操作步骤 → 预期结果」的可执行条目。
>
> 判定纪律：逐项打勾并填写结论；任何一项与预期不符都按**缺陷**处理（先修 spec 或代码，
> 不允许以「大概如此」通过）。数据面协议正确性的**最终验收**在
> [interop-testing.md](interop-testing.md)（与 Linux `wg` 对端互操作），本清单是其前置。

| 宿主机 | 已装 `wireguard-tools` / `qrencode`（导入测试用）、`python3`（生成配置） |

**准备测试配置**（宿主机执行，产物用于导入与互操作）：

```bash
wg genkey | tee priv.key | wg pubkey > pub.key        # 本机（手机）密钥对
wg genkey | tee peer-priv.key | wg pubkey > peer-pub.key  # 对端密钥对
cat > wg0.conf <<EOF
[Interface]
PrivateKey = $(cat priv.key)
Address = 10.7.0.2/24
DNS = 1.1.1.1
MTU = 1420

[Peer]
PublicKey = $(cat peer-pub.key)
AllowedIPs = 0.0.0.0/0, ::/0
Endpoint = <对端公网IP>:51820
PersistentKeepalive = 25
EOF
qrencode -t utf8 < wg0.conf                              # 二维码（扫码用）
zip -j tunnels.zip wg0.conf                               # 批量导入用
```

## 1. VPN 连接与生命周期（决策 0004/0005，specs/tunnel-connection.md）

- [ ] **VPN-1 首次授权框**：列表页拨开任一条隧道开关 → 系统弹出 VPN 授权框 → 同意。
  **预期**：授权后隧道进入「开」，状态栏出现 VPN（钥匙）图标；开关在结果确定前禁用。
- [ ] **VPN-2 拒绝授权**：授权框选择拒绝/取消。
  **预期**：开关弹回「关」，底部提示「建立连接时出错：用户未授权 VPN 服务」；再次拨动会重新弹授权框。
- [ ] **VPN-3 授权是否每次弹出**（spec 待验证）：首次同意后断开，再次连接同一隧道。
  **预期**：记录「是否再次弹出授权框」的事实（两种结果都接受，但需回写
  `specs/tunnel-connection.md` 待验证事项与 handbook）。
- [ ] **VPN-4 断开**：拨关已连接隧道开关。
  **预期**：开关「关」，状态栏 VPN 图标消失；无错误提示。
- [ ] **VPN-5 应用进程退出 → 系统断连**（决策 0004 §3、0005）：隧道连接中，从最近任务列表划掉本应用。
  **预期**：VPN 图标在可见时间内消失；重新打开应用，**全部隧道显示为「关」**（冷启动不做状态恢复猜测）。
  记录断连实际时延与 UI 表现。
- [ ] **VPN-6 系统设置关闭 VPN**（spec 待验证）：连接中进入「系统设置 → VPN」关闭本应用的 VPN，返回应用。
  **预期**：UI 开关自动纠正为「关」（说明能否拿到状态变更通知）。
  **若未纠正**：记录现象 → 需要按决策 0004 §3 的升级路径（VPN 进程写状态文件 + 心跳时间戳）处理，
  并同步更新 spec。
- [ ] **VPN-7 第三方 VPN 占用**（spec 新增文案）：先用其他 VPN 应用建立连接，再拨开本应用隧道开关。
  **预期**：提示「建立连接时出错：系统同时只允许一条 VPN 连接，请先断开其他 VPN 后重试」；
  开关弹回原位。（确认实际错误码是否为 `2203002`。）
- [ ] **VPN-8 切换隧道**：A 已连接，拨开 B 的开关。
  **预期**：A、B 开关同时禁用 → 自动先断 A 再连 B → B「开」、A「关」；若 B 失败，A 自动恢复为「开」。
- [ ] **VPN-9 统计与状态事件投递**（决策 0004 待验证 4）：连接后进入详情页观察 1 分钟；
  中途息屏 30s 再点亮。
  **预期**：详情页流量/上次握手时间每秒刷新；息屏/后台期间不崩溃，回到前台恢复刷新。
- [ ] **VPN-10 无网络下开启**：开飞行模式后拨开开关。
  **预期**：按建立失败处理，开关弹回，提示「建立连接时出错：<原因>」（系统返回的网络错误）；
  恢复网络后**不自动重连**。
- [ ] **VPN-11 配置不完整可连接**：导入一条无 `Address` / 无 `AllowedIPs`（或零 Peer）的配置并连接。
  **预期**：不做额外拦截，直接尝试建立（可能成功但无可用网络）。
