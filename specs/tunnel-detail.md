# 隧道详情

## 概述

隧道详情页以只读方式展示一条隧道的完整配置，并在隧道处于连接状态时提供
**实时运行统计**（各 Peer 的流量计数与上次握手时间，每秒刷新）。页面上任何
文本值都可点击复制。详情页也是进入编辑器和切换连接状态的入口。

## 入口

- 隧道列表页点击某条隧道；
- 编辑器保存新建/改名后的隧道时自动进入。

## 界面与操作

### 「本地（Interface）」卡片

- 卡片标题行右侧：**连接开关**（与列表页开关状态一致，行为见
  [tunnel-connection.md](tunnel-connection.md)）。
- 字段（**空值字段整行隐藏**）：

| 字段 | 展示 |
|---|---|
| 名称 | 隧道名称 |
| 公钥 | 完整 base64 公钥，单行省略显示 |
| 局域网 IP 地址 | 逗号分隔列表 |
| DNS 服务器 | 逗号分隔列表 |
| 搜索域名 | 逗号分隔列表（无则不显示） |
| 监听端口 | 数字（未设置则不显示） |
| MTU | 数字（未设置则不显示） |
| 应用过滤 | 「对 N 个应用生效」/「对 N 个应用不生效」（未配置则不显示） |

### 「远程（Peer）」卡片

每个 Peer 一张卡片，字段（空值隐藏）：

| 字段 | 展示 |
|---|---|
| 公钥 | 完整 base64，单行省略 |
| 预共享密钥 | 已配置时仅显示「已启用」（**永不显示密钥内容**） |
| 路由的 IP 地址（段） | 逗号分隔列表 |
| 对端 | `主机:端口` |
| 连接保活间隔 | 「每隔 N 秒」 |
| 流量 | 「接收：X，发送：Y」，人类可读单位（B 为整数，KiB/MiB/GiB/TiB 保留两位小数） |
| 上次握手时间 | 相对时间，由「天 / 小时 / 分钟 / 秒」逐段拼接后加本地化的「之前」
（如「4 分钟 27 秒之前」）；握手时间在未来或相同时显示本地化的「现在」；
时间显示以系统当前时间为准，不做时钟补偿 |

### 实时统计刷新

- 隧道处于**已连接**状态时，页面每秒刷新一次各 Peer 的「流量」与「上次握手时间」。
- 某 Peer 累计收发均为 0：隐藏其「流量」行；从未成功握手：隐藏其「上次握手时间」行。
- 统计读取失败：隐藏这两行（不显示错误）。
- 隧道未连接或页面退到后台：停止刷新；页面回到前台恢复。

### 一键复制

点击除预共享密钥外的任意字段值（名称、公钥、地址、对端等）将其复制到剪贴板，
提示 **「<字段名> 已复制到剪贴板」**（如「公钥 已复制到剪贴板」）。
预共享密钥行不可点击复制（其值为敏感信息且不展示）。

### 编辑入口

右上角「编辑」按钮进入隧道编辑器（见 [tunnel-editor.md](tunnel-editor.md)）。

## 错误与边界情况

| 场景 | 表现 |
|---|---|
| 配置加载失败 | 静态标签保留、配置相关字段值为空；开关按真实状态工作 |
| 隧道在后台被断开 | 停留本页，开关置为「关」并停止统计刷新 |
| 返回本页时隧道已不存在（已被删除） | 自动关闭本页返回列表，不提示（本项目新增保护，见差异） |
| 详情页开关切换失败 | 开关恢复原位，提示「建立连接时出错：<原因>」或「断开连接时出错：<原因>」（文案同 [tunnel-connection.md](tunnel-connection.md)） |

## 与上游的差异

- 复制提示：上游提示的主词同为字段名，但在较新版本的 Android 上不再显示提示
  （交由系统剪贴板提示）；本项目统一显示应用内提示。
- 隧道被删除后重新进入该页：上游无此保护，本项目新增「自动关闭返回列表」。
- 页面布局按平台规范实现，信息内容与上游一致。
