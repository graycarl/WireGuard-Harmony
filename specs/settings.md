# 设置页

## 概述

设置页集中放置与单条隧道无关的应用级功能：查看版本信息、导出全部隧道配置、
查看与导出应用日志、切换暗色主题。

## 入口

隧道列表页右上角「设置」图标按钮。

## 设置项

### 版本信息

- 显示应用名称与版本号，以及底层实现名称与版本
  （形如「WireGuard v1.x.x，userspace backend 1.0.x」；底层实现的名称与版本号
  在集成后按实际取值回填）。
- 纯展示，不可操作（上游点击版本项会打开 WireGuard 官网；本项目无官网入口，
  不响应点击）。

### 导出隧道配置

- 没有任何隧道时点击：直接提示「无法导出隧道配置：无隧道」，**不触发认证**
  （上游先认证再提示，本项目提前拦截，见差异）。
- 有隧道时：先要求**锁屏认证**（生物识别或锁屏凭证，规则见
  [privacy-security.md](privacy-security.md)）。
- 认证通过后，把**全部隧道**各序列化为一个 `<隧道名>.conf`（格式见
  [config-format.md](config-format.md)），打成一个 zip 压缩包，保存到用户选择的
  位置。
- 成功提示「已保存至 '<文件名>'」；失败提示「无法导出隧道配置：<原因>」。
- 注意：导出文件包含完整私钥，属敏感数据。

### 查看应用日志

- 点击进入日志查看页：按时间顺序（旧→新）展示应用自身记录的运行日志
  （含连接过程、错误信息），便于排障；仅当用户未手动上滑时，新日志自动滚动到底部。
- 日志内容**不包含私钥与预共享密钥**（见 [privacy-security.md](privacy-security.md)）。
- 日志页提供两个入口：
  - **导出日志文件**：把日志保存为文本文件，成功提示「已保存至 '<文件名>'」，
    失败提示「无法导出日志：<原因>」；
  - **分享日志文件**：通过系统分享把日志文件发给其他应用。

### 暗色主题

- 开关。开：使用暗色（黑夜）主题；关：跟随系统（默认）。
- 切换后即时生效，下次启动应用仍保持用户选择。
- 主题适用于**全部页面与对话框**（含隧道列表、详情、编辑器、日志页、半模态面板）。

## 裁剪说明（上游有、本页没有）

以下上游设置项在本页不提供（理由见 [README.md](README.md) 功能取舍总表）：
启动自动恢复、同时开启多条隧道、快速设置磁贴、安装命令行工具、
启用内核模块、外部应用远程控制、捐赠。

## 错误与边界情况

| 场景 | 表现 |
|---|---|
| 锁屏认证失败/取消 | 停留在设置页；单次识别失败提示「认证失败」、系统错误提示「认证失败：<原因>」（定义见 [privacy-security.md](privacy-security.md)），取消无提示 |
| 导出时无存储空间/无权限 | 「无法导出隧道配置：<原因>」 |
| 日志为空 | 日志页显示空白列表，不报错 |

## 与上游的差异

- 上游导出固定保存到系统「下载」目录；本项目由用户选择保存位置，
  导出成功以提示告知文件名（上游写回设置项摘要，本项目用即时提示）。
- 上游无隧道时仍先弹认证、通过后才提示「无隧道」；本项目直接提示、不触发认证。
- 上游日志直接读取系统运行日志；本项目展示应用自身记录的日志（可获取范围待验证）。
- 上游日志页有导出与分享两个入口，本项目保持一致。
- **暗色主题**：上游在新版本系统上已移除该开关、强制跟随系统（旧版本的「关」
  为强制亮色）；本项目保留手动开关（关 = 跟随系统，开 = 暗色）。
