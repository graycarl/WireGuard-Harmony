# 折叠屏外屏（小屏）适配

## 概述

阔折叠设备（如华为 Pura X）合起时有一块小尺寸、接近正方形的外屏。本应用支持
在**外屏上完整使用**：不展开手机即可查看隧道列表、开关连接、导入与编辑配置、
查看日志等全部功能。

当应用窗口小到一定程度（折叠屏外屏全屏、手机横屏、悬浮小窗等）时，应用自动进入
**紧凑布局**；窗口恢复常规大小时自动恢复常规布局。常规手机竖屏上的界面与交互
不因本功能发生任何变化。

## 入口与前提

- 应用出现在外屏的前提是：应用已完成外屏适配、上架应用市场，并通过平台的
  外屏展示审核（白名单机制）。审核通过后，用户可在系统的外屏应用管理中将
  本应用添加到外屏；应用内无需任何额外设置。
- 应用在折叠 / 展开切换时跟随窗口变化：停留在当前页面，**已输入未保存的内容
  不丢失**（如编辑器草稿、滚动位置、多选状态）。

## 紧凑布局（用户可感知）

窗口进入小尺寸状态时，界面自动收紧：

- 标题栏、列表行高、卡片与页面边距收窄，一屏可见更多内容；
- 标题与正文字号略微缩小，但所有文字保持完整可读；长文本的省略号截断规则与
  常规布局一致；
- 所有按钮、开关、复选框保持正常大小，可以可靠点按；
- 浮动「+」按钮缩小，不遮挡列表最后一行。

窗口恢复常规尺寸时，以上各项还原，不残留紧凑布局的显示效果。

## 各页面在小屏上的要求

- **隧道列表**：每行完整显示隧道名称与连接开关；多选模式的「已选择 / 全选 /
  删除」操作栏可用；空列表提示与「+」按钮不重叠。
- **隧道详情**：字段标签列收窄，字段值完整可读；点击复制、连接开关、
  「编辑」入口不受影响。
- **编辑器**：全部字段可正常输入；「保存 / 返回」始终可见；弹出键盘后，
  正在编辑的输入框与保存按钮可通过滚动到达。
- **设置 / 日志 / 扫码**：功能与常规布局一致，内容可滚动。
- **弹窗与面板**：添加面板、隧道命名对话框、应用过滤面板、提示弹窗在小屏上
  完整展示，按钮不被遮挡、可点按。

## 边界情况

- **布局切换途中**：紧凑 ↔ 常规布局切换（折叠 / 展开、拖动小窗边缘）时，
  正在进行的连接 / 断开操作不受影响，开关状态以真实连接状态为准。
- **极端小窗**（系统允许的最小窗口尺寸）：内容始终可滚动到达，连接开关可用；
  不保证单屏信息量。
- **系统弹窗**（VPN 授权框、锁屏认证、权限申请等）由系统绘制，其在小屏上的
  显示以系统为准。

## 与上游的差异

- 上游 WireGuard-Android 没有针对折叠屏外屏 / 小窗的紧凑布局；本功能为本项目新增。

## 待验证事项

- ~~外屏桌面能否直接启动本应用~~ **已确认（2026，官方渠道）**：不能。
  外屏显示三方应用是平台白名单制——完成外屏适配并上架应用市场后，需提交
  「外屏应用展示申请」，华为审核通过加白名单后应用才会出现在外屏；
  本地调试安装的版本无法添加（详见 docs/harmonyos-resources.md「折叠屏与外屏适配」）。
- 外屏上应用窗口的实际大小与显示密度：确认紧凑布局在外屏触发、在常规
  手机竖屏不触发（**外屏不支持本地真机调试，用 Pura X 模拟器验证**）；
- 外屏上使用相机扫码、系统 VPN 授权框、锁屏认证弹窗是否正常（模拟器 + 白名单后真机）；
- 折叠 / 展开切换时页面停留与编辑器草稿是否保持；
- 外屏上弹出键盘编辑隧道时，保存按钮是否始终可达。
