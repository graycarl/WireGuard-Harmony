# 隐私与安全

## 概述

隧道配置包含私钥等敏感信息。本 spec 定义应用在敏感信息的**查看、导出、展示、
存储**四个环节向用户提供的一致性保护行为。原则：敏感操作需锁屏认证、敏感页面
防截屏、敏感数据不出本机、详情页永不显示密钥内容。

## 保护规则

### 1. 查看私钥/预共享密钥前的认证

- 场景：隧道编辑器中，私钥、预共享密钥字段默认以密码样式遮蔽。
- 本次进入编辑器后**首次**点击/聚焦已有内容的密钥字段时，弹出系统锁屏认证
  （标题：「查看私钥前需要通过认证」）。认证方式与上游一致：**生物识别或锁屏凭证
  （PIN/图案/密码）均可**。
- 认证结果：
  - **通过**：字段明文显示；本次编辑会话内再聚焦密钥字段不再重复认证。
  - **单次识别失败**：保持遮蔽，提示「认证失败」。
  - **系统错误**：保持遮蔽，提示「认证失败：<原因>」。
  - **取消**：保持遮蔽，无提示。
  - **设备无任何认证能力**（既无可用生物特征、也未设置锁屏凭证）：直接明文显示，
    不阻断使用。
- 用户连续认证失败被系统锁定期间：页面保持遮蔽，展示系统返回的锁定提示；
  锁定解除后允许重试（锁定与解锁由系统提供）。
- 密钥字段为空时（新建隧道）点击不触发认证。

### 2. 导出配置前的认证

- 场景：设置页「导出隧道配置」。
- 导出前必须通过锁屏认证（生物识别或锁屏凭证，标题：「导出配置前需要通过认证」）；
  认证失败/取消则不导出。
- 设备无隧道时点击直接提示、不触发认证（见 [settings.md](settings.md)）。

### 3. 敏感页面防截屏

- 密钥被明文显示后，编辑器页面进入**防截屏/防录屏**状态（由系统的防截屏能力提供），
  直到离开编辑器。

### 4. 详情页永不显示密钥内容

- 隧道详情页只显示**公钥**；预共享密钥仅以「已启用」标识其存在（不可复制）；
  私钥不出现在详情页任何位置。

### 5. 日志不含密钥

- 应用日志与应用导出的日志文件**不包含私钥与预共享密钥**。

### 6. 本地保存承诺

- 所有隧道配置（含私钥）仅保存在本机应用内，不上传任何服务器，
  不集成任何统计、埋点服务。
- 本 spec 只承诺用户可感知边界：**卸载应用即彻底删除**。

### 7. 剪贴板使用

- 详情页/编辑器的一键复制只复制用户点击的具体字段（如公钥、地址）；
  预共享密钥不可复制；应用**不读取**剪贴板内容（除用户在输入框主动粘贴外）。

## 错误与边界情况

| 场景 | 表现 |
|---|---|
| 认证调用失败（硬件被占用/系统错误） | 提示「认证失败：<原因>」，保持遮蔽/不导出 |
| 用户连续认证失败被系统锁定 | 页面保持遮蔽并展示系统锁定提示；锁定解除后允许重试 |
| 设备无任何认证能力时的查看/导出 | 直接明文显示/直接执行导出（不虚构认证环节） |

## 与上游的差异

- 上游支持企业管控策略（可远程禁止导出配置与查看私钥）：本项目暂无对应管控能力，
  **不提供**；若平台企业管控能力后续可用，再补充。
- **认证会话范围**：上游页面旋转后仍视为同一会话、不再重新认证；本项目旋转/重建
  需重新认证（更严格）。
- 锁屏凭证回退、防截屏行为与上游一致。

## 待验证事项

- 平台锁屏认证能力：是否支持生物识别与锁屏凭证的组合认证、以及无硬件/未录入时的
  返回行为（用于判定「无任何认证能力」分支）。
