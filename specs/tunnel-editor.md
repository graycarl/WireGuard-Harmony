# 隧道编辑器

## 概述

隧道编辑器用于**手动创建**新隧道、**修改**已有隧道的配置、以及**重命名**隧道。
界面按 WireGuard 配置模型分为「本地（Interface）」卡片和若干「远程（Peer）」卡片，
字段与 wg-quick 配置一一对应（见 [config-format.md](config-format.md)）。
应用在输入阶段做即时限制，在保存阶段做完整校验，并给出具体错误原因。

## 入口

- 创建：隧道列表页「+」→「手动创建」，进入空白编辑器（标题：创建 WireGuard 隧道）。
- 编辑：隧道详情页右上角「编辑」按钮，进入时载入该隧道现有配置。

## 界面与操作

### 「本地（Interface）」卡片

| 字段 | 说明 | 输入行为 |
|---|---|---|
| 名称 | 隧道名称 | 仅允许 ASCII 字母、数字及 `_ = + . -`，最长 15 个字符；非法字符不进入、超长内容截断 |
| 私钥 | 本机私钥（base64，44 字符） | 默认以密码样式遮蔽；右侧「生成」图标按钮随机生成新私钥；输入框仅接受 `A-Za-z0-9+/` 且总长上限 44（第 44 位允许 `=`）；非法字符不进入、超长内容（含粘贴）截断至 44 |
| 公钥 | 由私钥自动派生，只读 | 私钥合法时实时显示派生公钥；私钥为空或非法时无内容、显示占位文字「（生成）」；点击可复制到剪贴板 |
| 局域网 IP 地址 | 隧道本机地址，可多个，逗号分隔 | 自由文本，例 `10.0.0.2/32, fc00::2/128` |
| 监听端口 | UDP 监听端口 | 纯数字；占位提示「（随机）」，留空表示随机 |
| DNS 服务器 | 可多个，逗号分隔 | 自由文本；非 IP 形式的条目视为 DNS 搜索域名 |
| MTU | 最大传输单元 | 纯数字；占位提示「（自动）」，留空表示自动 |
| 应用过滤 | 按应用选择走/不走 VPN | 按钮，文案随选择变化（见下） |

**私钥查看保护**：私钥字段已有内容且本次进入编辑器后尚未通过认证时，点击/聚焦
该字段先要求**锁屏认证**（生物识别或锁屏密码/图案，规则详见
[privacy-security.md](privacy-security.md)）。认证通过后本次编辑会话内不再重复询问
（页面旋转/重建需重新认证，见「与上游的差异」），字段明文显示，同时页面进入防截屏状态。
单次识别失败提示「认证失败」，系统错误提示「认证失败：<原因>」。

**「生成」按钮**：点击立即以新的随机私钥替换输入框内容（不二次确认，与上游一致）；
生成后字段仍保持遮蔽，其内容同样受查看保护；替换仅在保存后生效，未保存直接返回
则原私钥不变。对已有隧道重新生成并保存后，旧公钥即失效，需在对端同步更新，
否则隧道无法连通。

**应用过滤对话框**：

- 标题区两个标签页：「不生效」（选中的应用不走 VPN）与「生效」（仅选中的应用走 VPN），
  两种模式**互斥**；打开时定位到当前已配置的模式。
- 列表展示应用过滤能力可枚举到的、具有网络权限的应用（图标 + 应用名，按名称排序），
  逐项勾选；可枚举范围以平台能力为准（待验证），若枚举为空则显示空态「未找到可用应用」；
  枚举失败时提示「获取应用列表时出错：<原因>」并关闭对话框。
- 「全选」按钮文案固定为「全选」，点击在「全不选/全选」之间切换，作用于勾选集合
  （两个标签页共享，见下）。
- 确定按钮文案实时反映选择：未选任何应用时为「不设定过滤」；
  否则为「选定 N 个应用」。
- 勾选集合在两个标签页间**共享**（切换标签页不丢失勾选）；「确定」时按当前所在
  标签页的模式应用勾选集合；「取消」/返回不改动当前过滤设置。
- 确定后编辑器中的按钮文案更新为：「应用过滤」（未设过滤）/「对 N 个应用不生效」/
  「对 N 个应用生效」。

### 「远程（Peer）」卡片

可有多张。每张卡片字段：

| 字段 | 说明 | 输入行为 |
|---|---|---|
| 公钥 | 对端公钥（base64，44 字符） | 与私钥相同的 base64 输入限制 |
| 预共享密钥 | 可选，base64 44 字符 | 密码样式遮蔽；占位「（可选）」；查看保护同私钥 |
| 连接保活间隔 | 秒 | 纯数字；占位「（可选，不建议设置）」；输入框后缀显示「秒」 |
| 对端 | 服务器地址:端口 | 自由文本，例 `vpn.example.com:51820`、`[2001:db8::1]:51820` |
| 路由的 IP 地址（段） | 对端路由段，逗号分隔 | 自由文本，例 `0.0.0.0/0, ::/0` |
| 排除局域网 | 复选框 | 仅满足条件时显示（见下） |

卡片右上角「删除」图标按钮可移除该 Peer（不二次确认）。允许删除到**零个 Peer**
并保存（配置格式允许，见 [config-format.md](config-format.md)）；零 Peer 的隧道在
详情页远程区无卡片，连接不做额外拦截（见 [tunnel-connection.md](tunnel-connection.md)）。

**「排除局域网」复选框**：仅当**只有一个 Peer** 且其「路由的 IP 地址（段）」恰好
包含 `0.0.0.0/0`（或已等价展开为完整公网段列表）时显示：

- 勾选：`0.0.0.0/0` 被替换为等价的**公网 IPv4 段列表**（共 30 条固定网段，
  `0.0.0.0/5`、`8.0.0.0/7`、`11.0.0.0/8` … `208.0.0.0/4`，效果上排除
  10/8、172.16/12、192.168/16 等私有段与保留段），并自动把 DNS 服务器中的
  **IPv4 字面量**条目以 `/32` 主机路由形式补入路由段（保证 DNS 仍走隧道；
  搜索域名不补入，见「与上游的差异」）。
- 取消勾选：恢复为 `0.0.0.0/0`，并移除自动补入的 DNS `/32` 路由。
- 勾选后复选框保持显示；若用户手工修改路由段使其不再与公网段列表等价，
  复选框按显示条件自动隐藏。
- DNS 字段后续被修改时，自动补入的 DNS 路由跟随同步。

### 底部「添加节点」按钮

在末尾追加一张空白 Peer 卡片。

### 保存（右上角保存按钮）

点击保存时：

1. **完整校验**所有字段（规则见 [config-format.md](config-format.md)）；
   校验失败：停留在编辑器，底部提示具体错误（含出错字段与原因），不保存。
2. 校验通过后按三种情形处理：
   - **新建**：以输入的名称创建隧道，成功提示「成功创建隧道 '<名称>'」；
   - **改名**：名称与原来不同 → 先重命名再保存配置，可见提示为
     「已保存 '<新名称>' 的配置」（与上游不一致：上游重命名成功只记录日志、不弹提示，
     见「与上游的差异」）；
   - **修改**：直接保存配置，提示「已保存 '<名称>' 的配置」。
3. 保存成功后（三种情形均）退出编辑器并返回该隧道的详情页。
4. 保存失败停留在编辑器，按实际包裹形态提示：
   - 字段校验失败：仅提示错误本身（如「在 本地 的 私钥 字段发生了 密钥长度错误 的问题」）；
   - 名称为空/非法/超长：「无法创建隧道：名称无效」/「无法重命名隧道：名称无效」；
   - 新建重名：「无法创建隧道：名称 '<名称>' 已存在」；
   - 改名重名：「无法重命名隧道：名称 '<名称>' 已存在」；
   - 其他失败：「无法保存 '<名称>' 的配置：<原因>」。

## 错误与边界情况

| 场景 | 表现 |
|---|---|
| 名称为空/非法/超长 | 保存失败，提示「无法创建隧道：名称无效」或「无法重命名隧道：名称无效」 |
| 名称与其他隧道重复 | 按保存情形提示「无法创建隧道：名称 '<名称>' 已存在」或「无法重命名隧道：名称 '<名称>' 已存在」 |
| 任一字段校验失败 | 保存被拒绝，提示格式如「在 本地 的 私钥 字段发生了 密钥长度错误 的问题」 |
| 密钥长度/字符非法 | 提示「密钥长度错误」或「密钥中含错误字符」（输入框已拦截非法输入，一般仅出现在非常规输入或保存校验时） |
| 正在连接的隧道被修改配置 | 保存后断开并以新配置立即重连（短暂中断，见 [tunnel-connection.md](tunnel-connection.md)） |
| 编辑中切换后台/旋转 | 已输入内容不丢失；已明文显示的密钥恢复为遮蔽，再次查看需重新认证 |
| 未做任何修改直接返回 | 不保存、不提示 |

## 与上游的差异

- 上游编辑器在应用过滤对话框中列出「持有网络权限的应用」；本项目可枚举的应用范围
  以平台能力为准（待验证），空态与失败提示文案为本项目新增。
- 上游保存按钮在顶部菜单；本项目放在标题栏右侧，行为一致。
- **名称/密钥输入字符集**：上游输入过滤器实际允许任意 Unicode 字母/数字（如中文
  可被输入、保存时才报错），本项目收紧为仅 ASCII 字符集。
- **认证会话范围**：上游页面旋转后仍视为同一会话、不再重新认证；本项目旋转/重建
  需重新认证（更严格）。
- **重命名成功提示**：上游只记录日志；本项目额外提示「已保存 '<新名称>' 的配置」。
- **排除局域网的 DNS 路由补入**：上游以「不含冒号」判定 IPv4 条目，会把 DNS 搜索域名
  也补成 `域名/32` 并在保存时报解析错误（上游 bug）；本项目仅对真实 IPv4 字面量补入。
