# 隧道列表（首页）

## 概述

隧道列表是应用启动后的首页，展示本机已保存的全部 WireGuard 隧道。用户可以在这里
一眼看到每条隧道的名称和连接状态，快速开启/关闭隧道，进入隧道详情，批量删除隧道，
以及添加新隧道（导入或手动创建）。

## 入口

应用启动即进入本页。从隧道详情页、编辑器页、设置页返回后回到本页。

## 界面与操作

### 页面结构

- 顶部标题栏：应用名称；右上角「设置」入口（图标按钮），点击进入设置页
  （见 [settings.md](settings.md)）。
- 中部：隧道列表。
- 右下角：圆形「+」浮动按钮（添加隧道）。

### 空态

- 没有任何隧道时，列表区显示占位提示：**「点击下方按钮添加隧道」**。

### 列表项

每条隧道一行，包含：

- **隧道名称**（左侧）。
- **连接开关**（右侧）：显示该隧道当前的连接状态（开启/关闭）。

列表排序：按隧道名称的**自然排序**排列——大小写不敏感，名称中的数字段按数值
比较（例如 `wg2` 排在 `wg10` 之前）；仅大小写不同的名称按原始字符串再比较
（上游对仅大小写不同的名称未定义稳定顺序，本项目修正，见差异节）。

列表项开关在连接结果确定前临时禁用（与详情页开关一致，见
[tunnel-connection.md](tunnel-connection.md)）。

### 点击列表项

- **点击行**：进入该隧道的详情页（见 [tunnel-detail.md](tunnel-detail.md)）。
- **点击开关**：开启或关闭该隧道（完整行为见 [tunnel-connection.md](tunnel-connection.md)）。
  开关操作不进入详情页。

### 长按列表项（多选模式）

- **长按**任意列表项进入多选模式，该项被选中；此后**点击**其他行切换选中状态。
- 进入多选模式后：
  - 顶部标题变为 **「已选择 N 个隧道」**（标题栏被多选操作栏取代，设置入口不显示）；
  - 顶部出现操作：**全选**、**删除**（「全选」始终为选中全部，再次点击不变为取消全选）；
  - 「+」浮动按钮隐藏；
  - 再取消全部选中、或按系统返回键，退出多选模式，恢复正常状态。
- 点击**删除**：删除所有选中的隧道（不要求二次确认，与上游一致；删除不可恢复，
  配置中的私钥一并销毁），随后显示结果提示并**自动退出多选模式**：
  - 全部成功：「成功删除了 N 项」；
  - 有失败：「无法删除 N 项：<原因>」（N 为失败项数；逐项统计，见「与上游的差异」）。
- 删除处于**已连接**状态的隧道：先断开再删除；断开失败的项计入失败数，整批继续
  （完整规则以 [tunnel-connection.md](tunnel-connection.md)「删除隧道」为准）。

### 添加隧道（「+」按钮）

点击「+」按钮，从底部弹出半模态面板，提供三个选项：

1. **导入配置或压缩包**：打开系统文件选择界面（见 [tunnel-import.md](tunnel-import.md)）。
2. **扫描二维码**：打开扫码界面（见 [tunnel-import.md](tunnel-import.md)）。
   设备无摄像头或相机不可用时此项不显示。
3. **手动创建**：进入空白的隧道编辑器（见 [tunnel-editor.md](tunnel-editor.md)）。

面板点击遮罩或选择一项后关闭。

## 错误与边界情况

| 场景 | 表现 |
|---|---|
| 开启隧道失败（未授权、对端不可达等） | 开关恢复原位，底部提示「建立连接时出错：<原因>」 |
| 关闭隧道失败 | 开关恢复原位，底部提示「断开连接时出错：<原因>」 |
| 删除部分失败 | 提示「无法删除 N 项：<原因>」，失败的隧道保留 |
| 导入/创建成功或失败 | 底部显示对应提示（见 [tunnel-import.md](tunnel-import.md)） |

## 与上游的差异

- 上游列表页有一个常驻的更新提示（含「下载 & 更新」操作）：本项目不内置更新器，
  无此元素。
- 上游在多选模式下「+」按钮有缩放动画：动画细节不作规格要求，仅要求隐藏/恢复。
- **删除失败计数**：上游批量删除任一失败时提示的计数恒为 0（整批抛异常），
  本项目修正为按实际失败项数提示。
- **排序**：上游对仅大小写不同的名称未定义稳定顺序，
  本项目以「大小写不敏感比较，相同则按原始字符串比较」补齐。
