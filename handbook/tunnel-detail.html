隧道详情

一条隧道的完整配置都集中在这一页。隧道处于连接状态时， 这里还会实时显示每个对端的流量与上次握手时间；点击任意字段值即可复制。 本页是只读视图，想改动配置请点右上角的「编辑」。

1什么时候会看到这一页

  • 从列表进入：在隧道列表（首页）点击某条隧道行 （开关以外的任意位置）。
  • 保存后自动进入：在隧道编辑器里保存 隧道（新建、改名或仅修改配置）时，应用会自动打开这条隧道的详情页。

这一页同时是两个操作的入口：右上角「编辑」进入编辑器； 「本地」卡片标题行右侧的连接开关可直接连接或断开（与列表页的开关一致， 详见连接与断开）。

2界面一览

页面由标题栏和两张卡片组成：上面是「本地」卡片（本机侧的配置）， 下面是「远程」卡片（对端信息，每个对端各一张）。

本页是只读的：所有内容都只能查看和复制，不能在这里直接改动。 要修改配置请点右上角「编辑」。另外，页面上显示的名称、开关状态都跟随真实数据： 隧道被断开后，回到本页开关就会显示最新状态。

3「本地」卡片里都有什么

这张卡片对应配置里本机一侧（Interface）的内容。没有值的字段会整行隐藏， 所以不同隧道的卡片行数可能不一样。

字段你会看到没有值时
名称隧道名称整行隐藏
公钥完整的公钥；一行放不下时末尾用省略号截断整行隐藏
局域网 IP 地址逗号分隔的地址列表（如 10.0.0.2/24）整行隐藏
DNS 服务器逗号分隔的列表整行隐藏
搜索域名逗号分隔的列表整行隐藏
监听端口数字（如 51820）整行隐藏
MTU数字（如 1420）整行隐藏
应用过滤「对 N 个应用生效」或「对 N 个应用不生效」整行隐藏
公钥显示为一串 base64 字符，过长时会被截断——这只是显示效果， 点击该行复制到剪贴板的仍是完整内容。

4「远程」卡片里都有什么

这张卡片对应配置里的对端（Peer）。每个对端一张卡片，配置里有几个对端， 页面上就有几张「远程」卡片，自上而下排列。字段同样遵循「没有值就整行隐藏」。

字段你会看到没有值时
公钥完整的公钥；一行放不下时末尾用省略号截断整行隐藏
预共享密钥配置了只显示「已启用」——永不显示密钥内容，也不能点击复制整行隐藏
路由的 IP 地址（段）逗号分隔的地址或网段列表（如 0.0.0.0/0）整行隐藏
对端主机:端口（如 vpn.example.com:51820）整行隐藏
连接保活间隔「每隔 N 秒」整行隐藏
流量「接收：X，发送：Y」，其中 X、Y 为人类可读单位：字节（B）显示整数， KiB / MiB / GiB / TiB 保留两位小数 见第 5 节（收发都为 0、或读取失败时隐藏）
上次握手时间相对时间，由「天」「小时」「分钟」「秒」逐段拼接后加上「之前」， 如「4 分钟 27 秒之前」 见第 5 节（从未成功握手、或读取失败时隐藏）
「上次握手时间」以系统当前时间为准，应用不做时钟补偿。 如果记录到的握手时间晚于或等于系统当前时间（例如设备时钟被调回过）， 这一行显示为「现在」。

预共享密钥属于敏感信息，所以它的处理方式和别的字段不同：只用一个「已启用」表明 「配置里有这一项」，内容既不显示也不能复制。原因见 隐私与安全。

5实时统计怎么刷新

隧道已连接时，页面每秒刷新一次每个对端的「流量」和「上次握手时间」， 不需要你手动下拉或切换页面。

情况你会看到
隧道已连接每个对端的「流量」与「上次握手时间」每秒刷新一次
某个对端累计接收和发送都是 0该对端不显示「流量」行
某个对端从未成功握手该对端不显示「上次握手时间」行
统计读取失败这两行都不显示，页面不会弹出任何错误
隧道未连接停止刷新，数值不再变化
页面退到后台停止刷新；回到前台后自动恢复
隧道在后台被断开你仍停留在本页，开关自动变回「关」，同时停止统计刷新
统计行会不会出现，取决于对端是否真的传过数据、握过手——空白不代表出错。 如果刚连上就看不到「流量」行，多半是还没有任何数据经过这条隧道。

6一键复制字段值

  1. 点击想要复制的任意字段值（名称、公钥、局域网 IP 地址、DNS 服务器、对端、 流量、上次握手时间等都可以）。
  2. 页面底部立即弹出提示「<字段名> 已复制到剪贴板」， 例如点公钥会提示「公钥 已复制到剪贴板」。
  3. 提示消失后即可到别处粘贴。
「预共享密钥」不能复制，这是有意设计的：它的内容属于敏感信息， 详情页永不显示、也不进剪贴板。相关保护规则见 隐私与安全。
复制的内容会进入系统剪贴板。应用本身不读取剪贴板内容 （只有你在输入框里主动粘贴时才会用到）。粘贴完敏感信息后，注意及时清理剪贴板。

7在本页连接与断开

「本地」卡片标题行右侧的开关，和列表页的开关是同一个：拨到「开」即连接， 拨到「关」即断开。连接时（至少首次）系统会弹出 VPN 授权框，点「允许」即可；之后是否每次都弹出以系统为准。

如果开关拨过去又弹回原位，说明这一步失败了：页面底部会提示 「建立连接时出错：<原因>」或「断开连接时出错：<原因>」， 开关回到真实状态。全部原因文案与排查步骤见 连接与断开。

页面上的开关状态永远以系统侧的真实状态为准：即使你在系统设置里关掉了 VPN， 或隧道在后台被断开，回到本页时开关都会自动回到正确的位置。

8常见问题

现象原因与处理
字段名都在，值却全是空白 这次读取隧道配置失败了：页面会保留静态的字段名（标签），配置相关的字段值显示为空。 此时开关仍按真实状态工作，连接/断开不受影响。
从别的页面回到详情页，详情页自己关掉并回到了列表 说明这条隧道已经不在了（例如你在别处删除了它）。应用会自动关闭本页、返回列表， 不会弹出提示——这是预期行为。
看不到「流量」行 两种情况：该对端累计接收和发送都是 0（还没有任何数据经过）；或者本次统计读取失败。 两种情况都只是不显示这一行，不会报错。
看不到「上次握手时间」行 两种情况：该对端从未成功握手（所以没有时间可显示）；或者本次统计读取失败。 连上之后稍等，握手成功就会重新出现。
数值一直不变 统计只在隧道已连接时每秒刷新。隧道未连接，或页面退到后台时会停止刷新； 回到前台、隧道重新连上后自动恢复。
开关自己变回了「关」 隧道在后台被断开了（例如你在系统设置里关闭了 VPN，或被其他 VPN 应用顶掉）。 你仍停留在本页，开关显示真实状态，统计也随之停止刷新。
点「编辑」以后 进入隧道编辑器，可修改名称与各项配置； 保存后自动回到本页，内容随之更新。
点预共享密钥那一行没有任何反应 设计如此：预共享密钥只显示「已启用」，内容永不显示、也不可复制， 详见隐私与安全。
