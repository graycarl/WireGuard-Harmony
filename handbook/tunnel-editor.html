隧道编辑器

手动填写、修改和重命名隧道配置的地方。界面按配置结构分成一张「本地」卡片 和若干张「远程」卡片，输入时就地拦截非法内容，保存前再做一次完整校验并给出具体原因。

1怎么进入编辑器

编辑器有两个入口，分别对应「新建」和「修改」两种用途：

  1. 手动创建（空白编辑器）：在隧道列表页点右下角的 「+」→ 选择「手动创建」，进入一张空白编辑器，标题为「创建 WireGuard 隧道」， 所有字段都从空开始。
  2. 编辑已有隧道：在隧道详情页点右上角的 「编辑」按钮，进入编辑器时会自动载入该隧道当前的配置，你只需要改动要改的字段。
两种入口用的是同一个编辑器：保存成功后会退出编辑器、回到该隧道的详情页。 新建与编辑之外的改名也在同一个地方完成——直接改「名称」字段即可（见第 8 节 保存）。

2界面一览

页面从上到下是：标题栏（左侧返回箭头与标题、右侧保存按钮）、「本地」卡片、 一张或多张「远程」卡片，以及最底部的「添加节点」按钮。

上图是「手动创建」时的编辑器结构（字段内容为举例）：示例中已经填了名称，还没生成私钥， 所以「公钥」位置显示占位文字「（生成）」；「监听端口」和「MTU」显示的是留空时的占位「（随机）」「（自动）」。 从详情页进入编辑时，各字段会显示该隧道已保存的内容。

3「本地」卡片：逐字段说明

字段含义怎么填
名称 隧道名称，列表和详情页显示的就是它。 仅允许 ASCII 字母、数字及 _ = + . -，最长 15 个字符； 非法字符不会进入输入框，超出长度的内容被截断。重名判断按完全一致（区分大小写）。
私钥 本机私钥（base64，44 字符），相当于这把隧道的「钥匙」。 默认以密码样式遮挡；仅接受 A-Za-z0-9+/，总长上限 44 （第 44 位允许 =）；非法字符不进入，超长内容（含粘贴）截断到 44。 右侧「生成」按钮可随机生成一把新私钥。查看内容需要先通过锁屏认证， 详见第 4 节。
公钥 由私钥自动派生，只读，不需要也不能手工填写。 私钥合法时实时显示派生出的公钥；私钥为空或非法时无内容，显示占位文字 「（生成）」。点击该字段可把公钥复制到剪贴板（提示「公钥 已复制到剪贴板」）。
局域网 IP 地址 隧道里本机的地址，可以有多个，逗号分隔。 自由文本，例如 10.0.0.2/32, fc00::2/128。
监听端口 本端接收对端数据的端口。 只能填纯数字；占位提示「（随机）」，留空表示随机。
DNS 服务器 连接后使用的 DNS，可多个，逗号分隔。 自由文本；不是 IP 形式的条目会被当作 DNS 搜索域名处理。
MTU 最大传输单元（一次传输的数据包大小上限）。 只能填纯数字；占位提示「（自动）」，留空表示自动。一般不需要改动。
应用过滤 按应用选择哪些应用走 VPN、哪些不走。 点击按钮打开对话框选择；按钮文案会随选择变化，详见第 7 节。
拿不准的字段（监听端口、MTU、应用过滤）直接留空／不设置即可， 应用会按「随机」和「自动」处理。

4私钥：查看保护与重新生成

「私钥」和「远程」卡片里的「预共享密钥」都算敏感内容，默认一律遮挡显示。

第一次看私钥内容要认证

  1. 点一下（或聚焦）已经有内容的密钥字段——本次进入编辑器后的第一次会先弹出 系统的锁屏认证，标题为「查看私钥前需要通过认证」。
  2. 用生物识别或锁屏凭证（PIN/图案/密码）验证，两者都可以。
  3. 认证通过后字段变为明文显示，本次编辑会话内再点密钥字段不会重复询问； 同时编辑器进入防截屏/防录屏状态，直到你离开编辑器。
认证结果表现
通过字段明文显示，本次编辑会话内不再重复认证。
单次识别失败保持遮挡，提示「认证失败」。
系统错误保持遮挡，提示「认证失败：<原因>」。
你点了取消保持遮挡，不提示。
连续失败被系统锁定页面保持遮挡并显示系统返回的锁定提示；锁定解除后可以重试。
设备没有任何认证能力既没有可用生物特征、也没设置锁屏凭证时，直接明文显示，不阻断使用。
两个例外：① 密钥字段为空时（新建隧道）点它不会触发认证； ② 页面旋转或重建后视为新的编辑会话，已明文显示的密钥会恢复为遮挡，需要重新认证。 完整的安全说明见隐私与安全。

「生成」按钮

  • 点击「生成」会立即用一把新的随机私钥替换输入框内容，不再二次确认。
  • 生成后字段仍然保持遮挡，内容同样受上面的查看保护。
  • 替换只有在保存之后才真正生效；没保存就返回，原私钥不变。
对已有隧道重新生成私钥并保存后，旧公钥立即失效——必须同时在对端（服务器或对等设备） 上更新成新的公钥，否则隧道将无法连通。

5「远程」卡片：逐字段说明

「远程」卡片可以有多张，每张描述一个对端；最底部的「添加节点」按钮会在末尾追加一张空白卡片。

字段含义怎么填
公钥 对端的公钥（base64，44 字符）。 与私钥相同的字符限制：仅接受 A-Za-z0-9+/，总长上限 44，第 44 位允许 =； 非法字符不进入，超长内容（含粘贴）截断到 44。这一项与私钥不同，默认就是明文。
预共享密钥 可选的对端预共享密钥（base64，44 字符），用于额外加固。 密码样式遮挡，占位提示「（可选）」；查看保护与私钥相同。
连接保活间隔 多久向对端发一次保活包，用来维持连接。 只能填纯数字，输入框右侧后缀显示「秒」；占位提示「（可选，不建议设置）」， 一般留空（不设置）即可。
对端 对端的服务器地址和端口。 自由文本，例如 vpn.example.com:51820、[2001:db8::1]:51820。
路由的 IP 地址（段） 哪些流量走这条隧道（对端路由段），逗号分隔。 自由文本，例如 0.0.0.0/0, ::/0（表示全部流量都走隧道）。
排除局域网 把所有流量走隧道、但保留访问本地局域网的能力。 复选框，只在满足条件时出现，详见第 6 节。
卡片右上角的删除图标按钮会直接移除这张「远程」卡片，不再二次确认。 允许把「远程」卡片删到零个并保存：这样保存出来的隧道在详情页的远程区没有内容， 连接时也不会被额外拦截（连接行为见连接与断开）。

6「排除局域网」复选框

这个复选框只在同时满足下面两个条件时出现：

  • 当前只有一个「远程」卡片；并且
  • 它的「路由的 IP 地址（段）」恰好包含 0.0.0.0/0 （或者已经是等价的完整公网段列表）。

勾选与取消的效果：

操作发生了什么
勾选 0.0.0.0/0 被替换成等价的公网 IPv4 段列表（共 30 条固定网段，从 0.0.0.0/5、8.0.0.0/7、11.0.0.0/8 一直到 208.0.0.0/4）——效果上就是排除掉 10/8、172.16/12、192.168/16 等私有段与保留段； 同时把「DNS 服务器」里的 IPv4 条目以 /32 主机路由的形式补进路由段， 保证 DNS 请求仍然走隧道。
取消勾选 路由段恢复为 0.0.0.0/0，并移除刚才自动补入的 DNS /32 路由。
  • 勾选后复选框会继续显示；如果你手工把路由段改得不再与公网段列表等价，复选框会自动隐藏。
  • 勾选之后再去修改「DNS 服务器」，自动补入的 DNS 路由会跟着一起同步更新。
  • 只有是 IPv4 字面量的 DNS 条目才会被补入路由；DNS 搜索域名不会被补入。

7应用过滤对话框

点「本地」卡片里的「应用过滤」按钮打开对话框。

  • 两个标签页，二选一：「不生效」（勾选的应用不走 VPN）与「生效」 （只有勾选的应用走 VPN）。两种模式互斥，打开时会定位到你当前已经配置的那个模式。
  • 应用列表：列出可被应用过滤识别的、具有网络权限的应用（图标 + 应用名）， 并且按名称排序；逐项勾选即可。能列出哪些应用由系统决定。 如果一个都没列出来，会显示空态「未找到可用应用」；如果读取失败，会提示 「获取应用列表时出错：<原因>」并关闭对话框。
  • 「全选」按钮：文案固定为「全选」，点一下在「全不选/全选」之间切换， 作用范围是当前的勾选集合。
  • 确定按钮的文案会实时反映你的选择：一个应用都没选时是「不设定过滤」； 选了应用则是「选定 N 个应用」。
  • 两个标签页共享同一份勾选：来回切换标签页不会丢失已经勾选的应用； 点「确定」时，按你当前所在标签页的模式来应用这份勾选集合。
  • 点「取消」或按返回键关闭对话框，都不改动现有的过滤设置。

确定之后，编辑器里的按钮文案会相应变化：

你的选择编辑器按钮文案
没有设置过滤（在对话框里一个都没选并确定）应用过滤
在「不生效」标签页下选定 N 个应用对 N 个应用不生效
在「生效」标签页下选定 N 个应用对 N 个应用生效

8保存

填好后点右上角的「保存」。

  1. 保存时会先把所有字段完整校验一遍。任何一处不合格都不会保存， 你会留在编辑器里，底部给出具体错误（指出出错字段和原因），例如 「在 本地 的 私钥 字段发生了 密钥长度错误 的问题」。
  2. 校验通过后按情形保存，并给出对应提示：
    情形提示
    新建（从「手动创建」进来的空白编辑器）成功创建隧道 '<名称>'
    改名（名称和原来不一样）已保存 '<新名称>' 的配置
    修改（名称没变）已保存 '<名称>' 的配置
  3. 三种情形保存成功后都一样：退出编辑器，返回该隧道的详情页。
密钥长度不合规时原因显示为「密钥长度错误」；密钥里出现了允许字符以外的内容时 显示「密钥中含错误字符」（正常情况下输入框已经拦住了非法字符，这条只在少数非常规输入或保存校验时出现）。 端口、保活间隔、MTU 等数值非法时会附带具体原因，例如「必须为有效的 UDP 端口号」「必须为 0–65535 的整数」「必须为非负整数」。

保存失败时你会看到什么

失败类型提示
某个字段校验不合格 只提示错误本身，例如「在 本地 的 私钥 字段发生了 密钥长度错误 的问题」。
名称为空、含非法字符或超长 新建时「无法创建隧道：名称无效」；改名时「无法重命名隧道：名称无效」。
新建时名称与已有隧道重复 「无法创建隧道：名称 '<名称>' 已存在」。
改名时新名称与已有隧道重复 「无法重命名隧道：名称 '<名称>' 已存在」。
其他保存失败 「无法保存 '<名称>' 的配置：<原因>」。
你正在编辑的隧道如果处于已连接状态，保存后会先断开、再用新配置立即重连， 中间有短暂中断；开关会保持「已连接」的样子，如果重连失败则按真实状态显示并提示原因。 详情见连接与断开。

9常见问题

现象原因与处理
点私钥字段弹出系统认证框 这是私钥的查看保护，属于正常表现。用生物识别或锁屏凭证通过一次即可， 本次编辑会话内不再询问；旋转屏幕后需要重新认证。详见第 4 节。
提示「认证失败」或「认证失败：<原因>」 密钥保持遮挡。重新点击字段、再次认证即可；如果是系统错误，可按提示中的原因排查后重试。
名称明明没重复，却提示「已存在」 重名判断区分大小写：Home 和 home 被当作两个不同的名称。 请确认是否与某个已有名称完全一致，或换一个名称。
找不到「排除局域网」复选框 它只在「只有一个远程卡片，且路由段包含 0.0.0.0/0」时出现。 检查一下「远程」卡片的数量，以及路由段是否被手工改过。详见第 6 节。
应用过滤对话框里一个应用都没有 显示空态「未找到可用应用」；此时无法设置过滤，可以先直接确定（按钮显示「不设定过滤」）再退出。
勾选「排除局域网」后想去掉 再次点该复选框取消勾选：路由段会恢复为 0.0.0.0/0， 自动补入的 DNS /32 路由也会一并移除。
编辑了正在连接的隧道，保存后它断开又自动重连了 这是预期行为：编辑正在连接的隧道，保存后会断开并以新配置立即重连，有短暂中断。
编辑到一半切到后台或转屏 已经输入的内容不会丢失；已经明文显示的密钥会恢复为遮挡，再查看时需要重新认证。
什么都没改就返回了 未做任何修改直接返回时，不会保存也不会提示，直接回到上一页。
编辑过程中可以放心切到别的应用查资料，回来时输入的内容还在； 想放弃修改就直接返回——只要没点过「保存」，已保存的配置就不会变。
